Literature Manager - User Manual

This app is local-first. It stores data on your machine and does not require network access except when using an external AI API.

Quick Start

  1. Unzip the package to any folder.
  2. Double-click launch.bat.
  3. The backend starts in a console window and the UI opens in your browser.

If the UI opens before the backend is ready, refresh the page after a few seconds.

Core Features

  • Upload PDF/DOCX/TXT files and extract text.
  • Edit metadata: title, authors, year, journal, abstract, citation.
  • Manage categories and browse with sorting and pagination.
  • Search with full-text index (FTS5) and fallback keyword search.
  • Import/export in CSV or BibTeX formats.

Storage Location

The default storage root is Backend/uploads. You can change it in the UI (Storage Root section). The new path is saved to Backend/storage_config.json.

Agent (Optional)

The Agent can call an external API to suggest metadata. If the API is not configured or unavailable, the app uses rule-based extraction.

Environment variables (optional):

  • AI_PROVIDER=api
  • AI_CUSTOM_ENDPOINT=https://your-host/your-endpoint
  • AI_API_KEY=your-key
  • AI_MODEL=your-model

Troubleshooting

  • Cannot upload file: check file type (PDF/DOCX/TXT only).
  • Search results empty: ensure the backend is running.
  • Agent shows offline: configure API or use rule-based extraction.
